# 채용 면접 조편성 프로그램

지원자 리스트 엑셀 파일을 기준으로 지원부문별 4인 면접 조를 자동 편성하고, 2026년 6월 8일~10일 면접 일정을 랜덤 배정하는 Python 프로그램입니다. 44개 조를 3일 동안 운영하려면 단일 면접 트랙으로는 슬롯이 부족하므로, 일정 배정은 지원부문별 독립 면접 트랙 기준으로 같은 지원부문 안에서 시간이 겹치지 않게 처리합니다.

## 입력 엑셀 필수 컬럼

프로그램은 아래 컬럼명을 사용합니다.

| 컬럼 | 설명 |
| --- | --- |
| 지원부문 | 본사영업, 본사지원, 디지털금융 등 지원부문 |
| 지원번호 | 지원자 식별번호 |
| 매칭직무 | 조 편성 1순위 균형 기준 |
| 출신학교 | 조 편성 3순위 균형 기준 |
| 성별 | 조 편성 2순위 균형 기준 |

> 원본 설명의 B/E/F/H열 위치와 관계없이, 실제 엑셀의 헤더명이 위와 같아야 합니다.

## 설치

```bash
python -m pip install -r requirements.txt
```

## 실행

```bash
python interview_grouping.py 지원자_리스트.xlsx --seed 42
```

기본 결과 파일명은 `채용_면접_조편성_결과.xlsx`입니다. 다른 파일명으로 저장하려면 `-o` 옵션을 사용합니다.

```bash
python interview_grouping.py 지원자_리스트.xlsx -o 결과.xlsx --seed 42
```

## 조 편성 로직

1. 엑셀 파일을 불러오고 필수 컬럼을 검증합니다.
2. 지원부문별로 데이터를 분리합니다.
3. 각 지원부문 인원이 4명 단위로 나뉘는지 확인하고 필요 조 수를 계산합니다.
4. 각 조에 후보자를 1명씩 넣을 때 아래 우선순위의 중복 패널티를 계산합니다.
   - 매칭직무 중복: 가장 큰 패널티
   - 성별 중복: 두 번째 패널티
   - 출신학교 중복: 세 번째 패널티
5. 전체 데이터 구조상 완전 균등 배분이 불가능하면 `매칭직무 → 성별 → 출신학교` 순서로 우선 최적화합니다.
6. 09:00부터 50분 면접 및 10분 휴식 단위로 슬롯을 만들고, 12:00~13:00 점심시간을 제외합니다.
7. 조별 면접일자와 면접시간을 랜덤 배정하되, 지원부문별 독립 면접 트랙 안에서는 동일한 시간 슬롯을 한 번만 사용합니다.
8. 결과 엑셀 파일에 최종 결과, 상세 확인, 중복 검증 시트를 생성합니다.

## 결과 엑셀 시트

| 시트 | 컬럼 |
| --- | --- |
| 최종결과 | 지원부문, 조번호, 지원번호 |
| 상세확인 | 지원부문, 조번호, 면접일자, 면접시간, 지원번호, 매칭직무, 성별, 출신학교 |
| 중복검증 | 지원부문, 조번호, 인원, 매칭직무_중복수, 성별_중복수, 출신학교_중복수, 매칭직무_구성, 성별_구성, 출신학교_구성 |

## 기본 검증 조건

기본 실행에서는 아래 예상 조 수를 엄격하게 검증합니다.

| 지원부문 | 대상자 수 | 조 수 |
| --- | ---: | ---: |
| 본사영업 | 84명 | 21개조 |
